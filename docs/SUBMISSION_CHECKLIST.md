# First Commit — submission checklist

The original 6-page problem statement specifies **a 24-hour event** and the following deliverables. These must be submitted according to organizer instructions.

- [x] Completed web application source code (`app/`), dependencies, README, configuration.
- [x] Registration, login, logout, session persistence.
- [x] Authenticated one-to-one WebSocket messaging and SQLite persistence.
- [x] Extra functionality (Circles with invitations, typing, presence, seen receipts, search, edit/delete, reactions).
- [x] Automated test suite and runnable sample accounts.
- [x] Editable 14-slide PowerPoint pitch deck + PDF preview.
- [x] Spoken pitch notes + 90-second actual video recording instructions.
- [ ] Record and verify the running browser demonstration in your own environment.
- [ ] Push complete project to a **private** GitHub repository; keep private until hackathon ends.
- [ ] Upload PPT to Drive and enable **Anyone with the link → Viewer**.
- [ ] Record + upload the actual working-product demo to YouTube with **public** visibility.
- [ ] Optionally deploy with HTTPS/WSS and a **persistent** SQLite volume.
- [ ] Submit the repository URL, Drive PPT URL, and YouTube video URL with required access permissions.
- [ ] Add team name, team members, and any organizer-specific fields to slide 1 or final submission form.

**Critical**: The hackathon brief warns of disqualification if required public-link, repository, or upload requirements aren't satisfied. Validate each link from an incognito browser before submitting.
